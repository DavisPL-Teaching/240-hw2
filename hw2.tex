\textbf{Submission instructions:}
\begin{itemize}
\item Upload your solutions (as a PDF) and your code (as a \texttt{.zip} file, as with HW0: including the entire repository directory including config files like \texttt{Cargo.toml}, but excluding \texttt{target/}) in Gradescope.

\item Your PDF should be a single file \texttt{hw2.pdf}. If you use this LaTeX template to create your solutions, please remove the problem statements and include only your solutions.

\item The \texttt{main.rs} should contain your solutions to all coding parts (including functions and types as described above). Please do not modify function signatures. You are welcome to add additional functions and tests -- if you do so, please include all additional tests only at the bottom of the file.

\item You may add utility modules, like \texttt{mod util;} then \texttt{use util::...}, if you feel that you need them; but you should put all the main functions with the names as above in \texttt{main.rs}. Please double check on Piazza before importing any external crates in your \texttt{Cargo.toml}.

\item Make sure that \texttt{cargo build}, \texttt{cargo clippy}, \texttt{cargo test}, and \texttt{cargo fmt} (or \texttt{cargo fmt --check}) pass without any errors.
\end{itemize}
